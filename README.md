## What is XeroShield?

**XeroShield** is an affordable and powerful **FiveM anticheat** that protects your server from cheaters, mod menus and exploiters. It offers strong detections and a cloud admin panel.

XeroShield is updated every 1 to 7 days, so new cheats and bypasses are detected quickly. Every detection can be configured from your browser, and every ban, kick and warning is logged with the full details.

With the **global ban database**, a cheater banned on one XeroShield server can be kept out of every other server too. Your server is protected by the whole community, not only by your own staff.

## How to Get It

1. Purchase a license on **[xeroshield.net](https://xeroshield.net/#pricing)** and redeem it in your **[dashboard](https://xeroshield.net/dashboard)**.
2. Open your server in the dashboard, click **Manage resource**, then **Download resource**, and extract it.
3. Place the folder in your `resources` directory and add `ensure xeroname` to your `server.cfg`.
4. Restart your server, check the console for successful authentication and wait for XeroShield to install its module.
5. Restart the server once more when the installation is done.
